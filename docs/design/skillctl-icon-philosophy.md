# Quiet Relay

空间不是背景，而是受控流动的容器。形体以少量坚实节点和一条克制的连接关系构成，让留白承担秩序，让路径暗示分发。画面不解释机制，只以精确间距表现可靠边界；每个接点都应像经过无数次校准，体现顶尖工艺的沉着。

色彩取自温暖纸面、石墨黑与低饱和苔绿。材料感保持平整、细腻，不借助渐变或炫光制造虚假层次。深色负责结构，绿色只标记被允许的流向；配色需要逐像素推敲，呈现长时间打磨后的清晰与安静。

尺度通过一个稳定核心与较小目录节点形成节奏。连接线不是装饰，而是软链接般的视觉暗语：它靠近、转向、抵达，却不吞并源头。重复形态必须少而准确，以大师级执行保证缩至极小尺寸后仍然辨识明确。

构图在方形边界内保持偏心但平衡，避免机械居中带来的徽章感。负空间应让形体呼吸，同时把视线自然引向“源—连接—目标”的关系。所有圆角、线宽和间隔都应经过耐心调整，像一件由深厚经验与无数工时共同完成的微型器物。

信息完全寄托于形、色与位置，不使用文字、字母或表面化符号。最终作品应低调、专业、适合长期使用：近看有目录节点与受控分发的细节，远看只留下清楚而独特的轮廓。第二次审视不增加元素，只继续收紧比例与边缘，直到每个像素都显得必不可少。
